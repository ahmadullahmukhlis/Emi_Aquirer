Production controls

  • Test mode uses the local APS simulator and never sends cardholder data.
  • Production selection does not expose APS routes, certificates, HSM keys or test data.
  • Every financial request has an idempotency key.
  • PENDING means do not release cash or retry as a new transaction.
  • Cash-out is released only after confirmed approval.
  • Unknown outcomes require APS-approved reversal/recovery.
